Data Models (Schema Design)The core of the MVP relies on three primary collections.User Collection:id, email, password_hash, role (Enum: PATIENT, PROVIDER, ADMIN), is2FAEnabled (default: false), createdAt.Profile Collection (One-to-One with User):userId, fullName, dateOfBirth, bloodGroup, allergies (Array), chronicConditions (Array), emergencyContact.MedicalRecord Collection:id, patientId (Owner), title, category (Prescription, Lab Result, Visit Note), fileUrl (Path to storage), uploadedBy (User ID), timestamp.2. Authentication & Authorization FlowWe will use JWT (JSON Web Tokens) stored in an HTTP-only cookie or a Bearer token for session management.Registration: Hashes passwords using bcrypt before saving.Login: Validates credentials and returns a JWT containing the userId and role.RBAC Middleware: A reusable function to protect routes based on the user's role.JavaScript// Example Middleware Logic
const authorize = (roles = []) => {
  return (req, res, next) => {
    if (!roles.includes(req.user.role)) {
      return res.status(403).json({ message: 'Access Denied' });
    }
    next();
  };
};
